DemoApp ASync
================

.. toctree::
   :includehidden:
   :maxdepth: 10

This is an example on how to call an API that is configured to be called **asynchronously**
(Invocation Mode: Asynchronous).

For details on how to configure an API to be called **asynchronously**,
please refer to the documentation of the API Gateway
:otc_docs:`Creating an API <api-gateway/umn/api_management/creating_an_api.html>`.
